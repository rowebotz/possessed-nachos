# Constitution Quest

A beautiful, interactive web app to learn the U.S. Constitution — with progress tracking, flashcards, quizzes, and a mouse-and-cheese learning game with voice-overs.

## Run locally

- Using Python HTTP server:

```bash
python3 -m http.server 8000 -d /workspace
# open http://localhost:8000/
```

Or just open `index.html` directly in a browser (paths are relative).

## Features
- Daily progress with streaks (localStorage)
- Reader with preamble and article summaries
- Flashcards and quizzes
- Mouse 🐭 & cheese 🧀 arcade: eat cheese to hear key concepts
- Theme toggle and voice toggle
